# Grading design / Método de correção — 0.2.2

## Workflow
1. Teacher supplies rubric and guidance; preparation produces a shared reference.
2. Teacher approves the reference. Count criteria use distinct valid items; qualitative criteria use seven standard levels or explicitly justified teacher exceptions.
3. Model assesses the answer against the approved reference. Evidence, gaps, errors, sufficiency and limitation impact support a descriptor selection.
4. Server validates coverage, compatibility and limits. A contradiction yields a provisional score and review reason; no automatic score inflation or reduction.
5. Deterministic integer-cent arithmetic preserves teacher weights; Excel and Word expose results and explanations.

## Validation and limitations
The official development snapshot passed 93 automated grading tests, TypeScript, ESLint and a production build on Windows, as reported by the maintainer. Two classroom pilot questions with different operations were reviewed qualitatively. This is not independent psychometric validation; repeated-run stability, other disciplines and final API costs were not established. The public snapshot itself has not been built in this session. Teacher oversight remains required. No real student material is included in this update.
